## 1. 제품 개요

MY DESK는 Windows 11 위에서 실행되는 개인용 통합 데스크톱 환경이다. 운영체제를 대체하지 않으며, Windows에서 실행되는 하나의 애플리케이션으로 메인 화면과 여러 기능 모듈을 제공한다. 사용자는 파일 관리, 개인 지식 정리, 자동화, 시스템 모니터링, 유틸리티, 과학 시뮬레이션, 로컬 AI 대화를 하나의 환경에서 수행한다.

### 1.1 핵심 목표

- 여러 개인용 도구를 일관된 화면과 조작 방식으로 통합한다.
- 인터넷 연결 없이 핵심 기능을 사용할 수 있다.
- 사용자 데이터는 기본적으로 PC 내부에 보관한다.
- 각 프로그램은 독립적으로 작동하면서 필요한 정보를 서로 연동한다.
- 로컬 AI가 사용자가 허가한 범위에서 다른 모듈의 기능을 이용한다.
- 기본 8개 모듈을 제공하고 이후 모듈을 추가할 수 있다.

### 1.2 기준 환경

| 항목 | 사양 |
|---|---|
| 운영체제 | Windows 11 |
| CPU | AMD Ryzen 7 7800X3D |
| GPU | NVIDIA GeForce RTX 3060 12GB |
| RAM | 16GB |
| 여유 저장 공간 | 약 200GB |

설계 참고 사양이며 성능 보장을 뜻하지 않는다. AI 모델과 음성 기능은 메모리·GPU 자원에 따라 선택적으로 활성화할 수 있어야 한다.

### 1.3 구성

| 구분 | 내용 |
|---|---|
| 기본 모듈 (8) | 파일 관리자, 지식 관리자, 자동화 도구, 시스템 모니터, 도구 상자, 시뮬레이션 실험실, 로컬 AI 비서, 통합 런처 |
| 공통 기능 | 메인 데스크톱, 창 관리, 알림, 설정, 데이터 관리 |

## 2. 메인 데스크톱과 전체 UI

### 2.1 메인 화면

MY DESK를 실행하면 메인 데스크톱이 표시된다. 구성 요소는 바탕화면 영역, 프로그램 아이콘, 작업 표시줄, 시작 메뉴, 알림 영역, 시계, 위젯, 실행 중인 프로그램 창이다.

바탕화면에는 프로그램 바로가기를 배치할 수 있다.

- 아이콘은 마우스로 이동하고, 위치는 다음 실행 때 복원된다.
- 아이콘 이름과 크기를 조절할 수 있다.
- 사용하지 않는 아이콘을 숨길 수 있다.

### 2.2 글래스모피즘 디자인

기본 디자인은 어두운 계열의 글래스모피즘이다. 고정 배경 이미지를 덮지 않고, **사용자가 Windows에 설정한 실제 바탕화면이 유리 패널 뒤로 비치는 방식**을 우선한다.

| 요소 | 기준 |
|---|---|
| 패널 | 반투명한 어두운 패널 |
| 배경 | 패널 뒤 배경의 흐림(블러) 효과 |
| 테두리 | 얇고 은은한 밝은 테두리 |
| 그림자 | 부드러운 그림자 |
| 모서리 | 적절한 둥글기 |
| 글자 | 배경과 관계없이 읽을 수 있는 대비 |
| 애니메이션 | 창 전환·패널 표시 애니메이션 |

**대체 모드:** 실제 배경 투시와 블러는 Windows 그래픽 환경과 UI 기술의 제약을 받을 수 있다. 지원되지 않거나 성능 문제가 생기면 반투명 단색 패널 등 대체 모드를 제공한다. **효과가 적용되지 않았는데 정상 작동하는 것처럼 표시하지 않는다.**

**사용자 조절 항목:** 패널 투명도, 블러 강도, 밝기, 강조 색상, 테두리 강도, 모서리 둥글기, 그림자, 애니메이션, 글자 크기. 변경 결과는 가능한 범위에서 미리보기로 확인한다.

### 2.3 작업 표시줄과 시작 메뉴

| 영역 | 구성 |
|---|---|
| 작업 표시줄 | 시작 메뉴, 고정 프로그램, 실행 중인 프로그램, 활성 창 표시, 시계·날짜, 알림·상태 아이콘 |
| 시작 메뉴 | 전체 프로그램, 고정 프로그램, 즐겨찾기, 최근 실행 프로그램, 검색 |

- 작업 표시줄에서 실행 중인 창을 선택해 전환한다.
- 시작 메뉴 검색은 프로그램 이름과 설명을 기준으로 하며, 입력하는 동안 결과를 갱신한다.

### 2.4 위젯

메인 화면에 배치할 수 있는 위젯: 시계, CPU·RAM·GPU 요약, 저장 공간, 최근 메모, 빠른 메모 입력, 최근 실행 프로그램.

- 위젯은 표시·숨김, 이동, 크기 조절을 지원한다.
- 표시 값은 실제 모듈의 데이터와 일치해야 한다.

## 3. 공통 창 관리

모든 프로그램은 공통 창 구조를 사용한다. 창에는 제목과 아이콘, 최소화, 최대화·복원, 닫기 버튼, 이동 영역, 크기 조절 경계가 있다.

| 동작 | 기준 |
|---|---|
| 이동 | 제목 표시줄을 잡아 이동 |
| 크기 조절 | 가장자리와 모서리로 조절 |
| 최소화 | 작업 표시줄에서 다시 열기 |
| 최대화 | 최대화와 복원 지원 |
| 다중 실행 | 여러 프로그램 동시 실행 |
| 활성 상태 | 활성 창과 비활성 창을 시각적으로 구분 |
| 기억 | 창 위치와 크기 기억 |
| 보정 | 창이 화면 밖으로 사라지지 않도록 위치 보정 |

**저장 보호:** 저장되지 않은 편집 내용이 있을 때 닫기를 요청하면 저장 여부를 확인한다. 자동 저장 중 오류가 발생하면 경고하고, 복구 가능한 임시 내용을 보존한다.

## 4. 파일 관리자

### 4.1 목적과 화면

PC의 드라이브, 폴더, 파일을 탐색하고 정리한다.

| 영역 | 내용 |
|---|---|
| 왼쪽 | 탐색 영역 (드라이브·즐겨찾기) |
| 상단 | 경로, 이동 버튼, 검색창 |
| 중앙 | 파일 목록 |
| 보조 | 선택 항목 정보, 선택적 미리보기 |

### 4.2 탐색과 표시

- 드라이브·폴더 이동, 뒤로·앞으로·상위 폴더, 즐겨찾기, 최근 위치
- 숨김 파일 표시, 확장자 표시
- 보기 방식: 큰 아이콘, 작은 아이콘, 목록, 자세히
- 정렬: 이름·형식·크기·수정 날짜, 오름차순·내림차순

### 4.3 파일 작업

- 폴더 생성, 복사, 이동, 이름 변경, 삭제, 휴지통 이동
- 속성 확인, 경로 복사, 여러 항목 선택
- 기본 연결 프로그램으로 열기
- 복사·이동 중 진행률과 현재 항목 표시, 가능한 작업은 취소 지원

### 4.4 검색과 미리보기

- 검색 조건: 파일명, 확장자, 파일 형식, 크기, 수정 날짜, 검색 폴더
- 파일 내용 검색은 지원되는 텍스트 형식에 한정한다. 모든 형식의 내부 내용을 검색한다고 가정하지 않는다.
- 검색 색인을 사용한다면 색인 대상과 갱신 상태를 확인할 수 있어야 한다.
- 이미지·일반 텍스트·지원되는 PDF는 내부 미리보기를 제공할 수 있다. 미지원 형식은 이유를 표시하고 기본 프로그램으로 열게 한다.

### 4.5 안전

- 삭제, 영구 삭제, 덮어쓰기, 대량 변경 전에 대상과 결과를 보여주고 확인을 받는다.
- 권한 부족, 파일 잠김, 이름 충돌, 저장 공간 부족을 구체적으로 안내한다.

### 4.6 연동

- 자동화 도구는 파일 관리자에서 선택한 폴더를 대상으로 삼을 수 있다.
- AI는 사용자가 허용한 범위에서 파일을 검색할 수 있다.

## 5. 지식 관리자

### 5.1 목적과 자료 유형

메모, 문서, 학습 노트, 아이디어, 프로젝트 기록, 체크리스트, 실험 기록, 참고 링크를 보관하는 개인 지식 공간이다.

### 5.2 화면

| 영역 | 내용 |
|---|---|
| 왼쪽 | 폴더와 태그 |
| 중앙 | 문서 목록 |
| 오른쪽(또는 별도 화면) | 편집기 |

좁은 화면에서는 목록과 편집기를 전환해 사용한다.

### 5.3 편집

- 제목·본문 작성, 서식, Markdown
- 목록, 표, 인용, 코드, 체크리스트, 링크, 첨부파일
- 태그, 폴더 분류

### 5.4 저장과 관리

- 자동 저장이 기본이며 저장 상태를 표시한다.
- 저장 실패 시 임시 내용을 보존하고 알린다.
- 폴더 생성·이름 변경, 문서 이동, 즐겨찾기, 최근 문서
- 휴지통·복구, 문서 내보내기·가져오기
- 프로그램 종료나 오류 후에도 최근 저장본을 복구할 수 있다.

### 5.5 검색과 링크

- 제목, 본문, 태그, 폴더를 검색하고 일치한 문맥을 보여준다.
- 관련 문서끼리 내부 링크로 연결한다. 문서 이동·삭제로 링크가 끊기면 알린다.

### 5.6 AI 보조

AI는 문서 요약, 제목·태그 추천, 문장 다듬기, 여러 문서의 공통 내용 정리, 관련 문서 검색, 초안 생성을 지원할 수 있다.

**AI는 원문을 자동으로 덮어쓰지 않는다.** 수정 제안을 보여주고 사용자가 적용한다.

## 6. 자동화 도구

### 6.1 목적과 구성

반복적인 로컬 작업을 조건에 따라 수행한다. 자동화 규칙은 다음 요소로 구성된다.

**실행 조건 → 필터 조건 → 실행 작업 → 예외 처리 → 실행 결과**

### 6.2 실행 조건

| 조건 | 비고 |
|---|---|
| 사용자 수동 실행 | |
| MY DESK 시작 시 | |
| 지정 시간 | 프로그램 종료·절전 상태에 따라 제한될 수 있음 |
| 지정 폴더에 파일 생성·변경 시 | 프로그램 종료·권한 상태에 따라 제한될 수 있음 |

예약 실행과 폴더 감시의 제한 사항은 화면에 동작 조건으로 표시한다.

### 6.3 필터와 작업

- **필터:** 확장자, 파일명 패턴, 크기, 생성·수정 날짜, 원본 폴더. AND·OR 조합으로 확장할 수 있다.
- **작업:** 폴더 생성, 파일 복사·이동·이름 변경·분류, 파일 목록 생성, 지식 관리자 기록 생성, 결과 알림

### 6.4 편집과 미리보기

- 규칙을 단계별로 표시하고 단계 추가·삭제·수정·순서 변경을 지원한다.
- 실행 전에 대상 파일, 원본·대상 경로, 변경될 이름, 충돌, 삭제 항목을 미리 보여준다.
- 삭제·덮어쓰기·대량 변경은 명시적 확인을 요구한다.

### 6.5 실행 기록과 충돌

- 실행 기록: 규칙명, 시작·종료 시각, 처리 수, 성공·실패·건너뜀, 오류 원인, 취소 여부
- 같은 규칙의 중복 실행, 여러 규칙이 같은 파일을 동시에 변경하는 충돌을 감지한다.
- 충돌 시 임의로 덮어쓰지 않는다.

## 7. 시스템 모니터

### 7.1 대시보드

CPU, RAM, GPU, 저장 장치의 핵심 사용량을 카드와 그래프로 표시한다. 항목을 선택하면 상세 화면을 연다.

### 7.2 항목별 상세

| 항목 | 표시 내용 |
|---|---|
| CPU | 전체·코어별 사용률, 현재 클럭, 프로세서 정보, 온도·전력(지원 시) |
| RAM | 전체 용량, 사용량, 사용 가능량, 사용률, 시간 그래프 |
| GPU | 이름, 사용률, 전용 메모리, 공유 메모리·온도·전력·클럭·팬 속도(지원 시) |
| 저장 장치 | 드라이브 이름, 전체·사용·남은 용량, 사용률, 확인 가능한 장치 상태 |
| 프로세스 | 이름, CPU, 메모리 사용량 |

프로세스 종료는 선택 기능이며, 시스템 프로세스 보호와 확인 절차가 필요하다.

### 7.3 그래프와 기록

- 실시간 그래프, 표시 시간 범위
- 현재·평균·최대값
- 선택적 기록 저장
- 사용자가 정한 사용률·온도 기준을 넘으면 알림

### 7.4 센서 정확성

센서 정보는 하드웨어와 드라이버에 따라 다르다.

- **측정할 수 없는 값은 0으로 표시하지 않고 '측정 불가' 또는 '지원되지 않음'으로 표시한다.**
- 측정 시각과 갱신 주기를 알 수 있어야 한다.

## 9. 시뮬레이션 실험실

### 9.0 공통 원칙

과학·수학 현상을 직접 조작하고 관찰한다. 애니메이션만 보여주지 않고 **입력 변수와 계산 결과가 연결**되어야 한다.

- **실험 화면 구성:** 설명, 장면, 변수 패널, 시작·일시 정지·초기화, 측정 결과, 그래프, 단위와 모델 가정
- 드래그 가능한 실험은 마우스 조작과 수치 입력을 함께 제공한다.
- 그래프와 장면은 같은 계산 상태를 사용한다.
- 실험 결과와 입력값을 저장하고 지식 관리자에 기록할 수 있다.

### 9.1 전자기 유도 — 코일에 넣고 빼는 막대자석

**변수**

| 변수 | 범위 |
|---|---|
| 자석 속도 | 0~2 m/s |
| 자기장 세기 | 0.1~0.5 T |
| 코일 감은 횟수 | 50~500회 |
| 코일을 향하는 극 | N / S |

**장면:** 막대자석, 코일, 자기력선, 검류계, 유도 기전력 수치, 시간-기전력 그래프

**조작:** 자석 드래그 또는 자동 왕복 운동, 속도·극 변경, 초기화

**계산:** 자기 선속의 시간 변화로 유도 기전력을 계산한다. 전류를 표시하려면 코일 저항과 회로 부하 조건을 모델에 포함한다.

**검증 기준**

- 같은 조건에서 자석이 빠를수록, 감은 횟수가 많을수록 기전력이 커진다.
- 자석이 정지해 선속이 변하지 않으면 기전력은 0이다.
- 접근과 후퇴 시 기전력 부호가 반대다.
- 자석 극을 바꾸면 방향 관계가 반전된다.

**결과 표시:** 기전력(mV), 전류(모델 조건이 있을 때), 방향, 검류계 편향, 시간 그래프

### 9.2 전류의 자기 작용 — 직선·원형·솔레노이드

**변수** (선택한 형태에 적용되지 않는 변수는 비활성화)

| 변수 | 범위 | 적용 형태 |
|---|---|---|
| 도선 형태 | 직선 / 원형 / 솔레노이드 | 전체 |
| 전류 | 0~10 A | 전체 |
| 전류 방향 | 정 / 역 | 전체 |
| 측정 거리 | 1~20 cm | 직선·원형 |
| 원형 도선 반지름 | 2~10 cm | 원형 |
| 단위 길이당 감은 횟수 | 100~2000회/m | 솔레노이드 |

**장면:** 흰색 바닥판을 비스듬히 내려다보는 3D 시점, 구리색 도선, 전류 화살표, 자기력선, 나침반 8개(N극·S극 색 구분), 측정점

**검증 기준**

- 같은 조건에서 전류가 커지면 자기장이 강해진다.
- 전류 방향을 반전하면 자기장 방향도 반전된다.
- 직선 도선은 도선을 중심으로 원형 자기장을 만들고, 거리가 멀수록 세기가 감소한다.
- 원형 도선과 솔레노이드는 각 기하 구조에 맞는 모델을 사용한다.
- 솔레노이드 내부와 외부의 특성을 구분한다.

**결과 표시:** 자기장 세기(μT 등), 방향, 자기력선, 나침반 방향

### 9.3 무선 충전 — 두 코일 사이의 전자기 유도

**변수**

| 변수 | 범위 |
|---|---|
| 코일 간 거리 | 0~3 cm |
| 좌우 어긋남 | 0~3 cm |
| 송신 전류 | 0~2 A |
| 전류 종류 | 교류 / 직류 |

**장면:** 충전 패드 송신 코일, 휴대전화 수신 코일, 자기장 선, 드래그 가능한 휴대전화, 송·수신 전류 그래프, LED, 배터리, 유도 전류·전력 표시

**조작:** 휴대전화 드래그 또는 수치 입력으로 거리·위치 변경

**계산:** 교류에서는 시간에 따라 변하는 자기장과 수신 코일의 유도 기전력을 계산한다. 충전 전력은 유도 전압만으로 결정되지 않으므로 수신 회로, 부하, 효율을 모델에 포함한다. 배터리 충전량은 전달 전력과 시간에 따라 변한다.

**검증 기준**

- 거리가 멀거나 정렬이 어긋나면 일반적으로 결합이 약해진다.
- 다른 조건이 같을 때 송신 전류가 커지면 유도 효과가 커진다.
- 일정한 직류는 과도 상태 이후 지속적인 유도를 만들지 않는다.

**결과 표시:** 수신 전압, 전류, 전달 전력, 모델상 효율, 배터리 충전량, 전류 그래프

**시각화 주의:** 실제 무선 충전기의 고주파 교류를 교육용으로 느리게 보여줄 수 있다. 시각화 속도와 계산 주파수가 다르면 이를 화면에 설명한다.

### 9.4 정확도와 실험 기록

- 이상적인 도선, 균일한 자기장, 단순화한 코일 구조 등 모델의 가정과 근사 범위를 표시한다.
- 계산하지 않는 효과를 실제로 반영한 것처럼 표현하지 않는다.
- 입력 변수, 결과, 그래프, 설명, 가정을 함께 저장하고 다시 불러올 수 있다.

## 10. 로컬 AI 비서

### 10.1 목적과 대화 화면

인터넷 없이 PC 안에서 실행되는 AI로 대화, 자료 검색, 문서 보조, MY DESK 제어를 제공한다.

- **화면 구성:** 대화 목록, 메시지, 입력창, 전송, 새 대화, 검색, 기록 삭제, 응답 중지, 복사
- AI가 로컬 자료를 참고했다면 출처를 확인할 수 있어야 한다.
- 기본 말투는 친근하고 자연스럽게 하되, 요청에 따라 기술 설명·문서 작성·간결한 답변 등으로 조절한다.

### 10.2 음성 대화

호출어 기반 시작을 목표로 한다.

**상태 흐름:** 대기 → 호출 감지 → 듣기 → 음성 인식 → 응답 생성 → 음성 출력 → 대기 복귀

- 화면에 마이크 활성화 여부와 처리 상태를 명확히 표시한다.
- 제공 기능: 호출어 켜기·끄기, 마이크 켜기·끄기, 음성 입력 시작·종료, 음성 출력 중지, 음성 속도·종류, 대화 종료
- 마이크 접근 거부나 장치 부재를 안내한다.
- **음성 기능이 실패해도 텍스트 대화는 가능해야 한다.**

### 10.3 모델 관리

- 사용 가능한 모델, 선택된 모델, 대략적인 크기와 자원 요구, 로딩·실행 상태를 표시한다.
- 모델 파일 누락·손상·메모리 부족을 안내한다.
- 텍스트 모델, 음성 인식, 음성 합성, 호출어 감지는 별도 구성 요소일 수 있으므로 기능별 상태를 구분해 표시한다.

### 10.4 기록과 기억

| 구분 | 의미 |
|---|---|
| 대화 기록 | 대화 내용 보관 |
| 장기 기억 | 이후 대화에 유용한 선호, 프로젝트 정보 등 |

사용자는 두 가지를 각각 확인·삭제할 수 있고, AI가 기억하는 항목을 직접 관리할 수 있다.

### 10.5 로컬 자료 검색

- 사용자가 허용한 폴더와 지식 관리자 자료만 검색한다.
- 검색 대상·제외 폴더·파일 형식·색인 상태·갱신 기능을 제공한다.
- 시스템 전체 파일을 무단으로 검색하지 않는다.

### 10.6 프로그램 제어와 권한

AI는 MY DESK가 제공하는 제한된 도구만 호출한다. (예: 프로그램 열기, 파일 검색, 시스템 사용량 조회, 메모 생성, 실험 실행) 요청이 모호하면 실행 전에 확인한다.

| 권한 등급 | 예시 | 처리 |
|---|---|---|
| 조회 | 사용량 조회, 파일 검색 | 요청이 모호하면 실행 전 확인 |
| 일반 작업 | 프로그램 열기, 메모 생성, 실험 실행 | 요청이 모호하면 실행 전 확인 |
| 변경 작업 | 파일 이동·이름 변경, 자동화 규칙 수정 | 변경 내용을 보여주고 확인 |
| 위험 작업 | 영구 삭제, 대량 변경, 시스템 설정 변경 | 명시적 승인 필수 |

- **AI가 스스로 권한을 높이거나 확인을 생략해서는 안 된다.**
- 오프라인 AI는 최신 웹 정보나 외부 실시간 정보를 알 수 없다. 로컬 자료가 없으면 모른다고 표시한다.

- 손상되었거나 등록되지 않은 모듈은 실행하지 않고 상태와 원인을 표시한다.

- 사용자는 저장 위치를 확인하고, 종류별로 백업·복원·내보내기·삭제할 수 있다.
- 휴지통으로 옮길 수 있는 데이터는 휴지통을 먼저 사용하고, 영구 삭제는 별도로 확인한다.
- AI 검색 범위와 자동화 작업 폴더는 사용자가 설정한다.
- 각 모듈은 필요한 데이터에만 접근한다.

## 15. 모듈 연동 시나리오

| 연동 | 시나리오 |
|---|---|
| AI ↔ 지식 관리자 | 특정 주제의 과거 노트를 요청하면 AI가 문서를 검색해 관련 부분을 요약하고, 원본 문서를 열 수 있게 한다. |
| AI ↔ 파일 관리자 | 최근 수정한 PDF를 요청하면 허용된 폴더에서 조건에 맞는 파일 목록과 경로를 보여준다. 사용자가 선택한 파일만 연다. |
| AI ↔ 시스템 모니터 | CPU·RAM·GPU·저장 공간의 현재값과 측정 시각을 가져와 요약한다. 누락된 센서는 측정 불가로 설명한다. |
| 자동화 ↔ 파일 관리자 | 다운로드 폴더에 들어온 PDF를 지정 폴더로 분류하는 규칙을 만들고, 실행 전에 대상과 결과를 미리 보여준 뒤 승인 후 실행·기록한다. |
| 시뮬레이션 ↔ 지식 관리자 | 실험 변수, 그래프, 결과, 모델 가정을 저장해 나중에 재현·비교한다. |

**연동 원칙**

- 연동은 사용자가 허용한 범위에서만 수행한다.
- 한 모듈의 오류가 다른 모듈 전체를 중단시키지 않는다.
- 연동이 실패하면 가능한 수동 작업 경로를 제공한다.

## 16. 오류와 예외 처리

| 영역 | 처리 대상 |
|---|---|
| 파일 | 누락, 권한 부족, 잠김, 용량 부족, 이름 충돌 |
| 지식 관리 | 저장 실패, 첨부 누락, 색인 불일치 |
| 자동화 | 중복 실행, 부분 실패 |
| 시스템 모니터 | 센서 수집 실패 |
| AI | 모델 로딩 실패, 메모리 부족, 음성 장치 오류 |
| 시뮬레이션 | 입력 범위 초과, 계산 실패 |

**오류 안내 원칙**

- 기술 코드만 보여주지 않고 **발생 대상, 원인, 가능한 해결 방법**을 함께 안내한다.
- 부분 성공과 전체 실패를 구분하고, 실제로 변경된 항목을 기록한다.
- 한 모듈의 오류가 MY DESK 전체 종료로 이어지지 않게 한다.

## 18. 사용성과 접근성

- 모든 주요 기능은 마우스로 사용할 수 있다. 자주 쓰는 기능에는 키보드 단축키를 제공할 수 있다.
- 아이콘만으로 의미가 불분명한 기능에는 설명을 제공한다.
- 글자와 배경의 대비를 확보하고, 애니메이션을 끌 수 있게 한다.
- 창이 작아져도 핵심 조작이 불가능해지지 않게 한다.
- 긴 작업은 진행 상태를 표시하고, 취소 가능한 작업은 취소 방법을 제공한다.

**버튼이 화면에 존재하는 것만으로 기능이 완료된 것은 아니다.** 실제 조작 결과가 기대한 동작과 일치하고 데이터가 보존되어야 한다.

| 파일 관리자 | 실제 파일 시스템과 결과 일치, 삭제·덮어쓰기 확인 작동 |
| 지식 관리자 | 재실행 후 내용 유지, 검색 정확성, 편집 중 복구 |

| 시뮬레이션 | 변수·계산·장면·그래프 일치, 물리 법칙의 핵심 관계 준수, 가정 표시 |

## 20. 최종 제품 정의

MY DESK는 Windows 11에서 작동하는 **오프라인 우선 개인용 통합 데스크톱 환경**이다. 기본 8개 모듈은 독립적으로 작동하면서 공통 창 관리, 디자인, 알림, 설정, 로컬 데이터 체계를 공유한다. 로컬 AI는 사용자의 허가 범위 안에서 다른 모듈을 활용해 자료 검색과 작업을 보조한다.

디자인은 실제 Windows 배경화면이 비치는 글래스모피즘을 지향하되 가독성·성능·호환성을 함께 고려한다.

**핵심 가치:** 통합성 · 오프라인 독립성 · 모듈 연동 · 개인화 · 확장성 · 신뢰성
